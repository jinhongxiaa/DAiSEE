# بارگذاری در GitHub و ساخت DOI

۱. ZIP را استخراج کنید. یک مخزن جدید با نام daisee-compact-workflow بسازید.
۲. محتوای داخل پوشه DAiSEE_Compact_GitHub را در ریشه مخزن بارگذاری کنید؛ README.md باید در ریشه دیده شود.
۳. فقط کد و مستندات این بسته را بارگذاری کنید. پوشه دیتاست، محیط مجازی، خروجی‌ها و وزن‌ها را اضافه نکنید. بارگذاری دستی وب الزاماً از .gitignore پیروی نمی‌کند.
۴. انتخاب لایسنس کد باید با اختیار صاحبان کد انجام شود؛ این بسته مجوزی را از طرف نویسندگان فرض نکرده است.
۵. برای DOI، مخزن را به Zenodo متصل کنید و یک Release نسخه‌دار بسازید؛ راه دیگر، بارگذاری همین آرشیو کد در Zenodo و تکمیل اطلاعات واقعی نویسندگان است.
۶. عنوان مقاله، نویسندگان، سال و مجوز را با اطلاعات واقعی تکمیل کنید. DOI نسخه منتشرشده و لینک مخزن را برای اصلاح Code Availability بفرستید.

README انگلیسی شامل نصب، مسیر دیتاست و دستورات اجراست. هیچ DOI آزمایشی در بسته درج نشده است.
