# Dataset and external assets

DAiSEE belongs to its original providers; this code package does not grant dataset rights.
Obtain the dataset and accept its terms at https://people.iith.ac.in/vineethnb/resources/daisee/index.html.
The provider restricts image use to research and prohibits providing images to second parties.
The historical study used this Kaggle mirror (version 1):
https://www.kaggle.com/datasets/olgaparfenova/daisee?select=DAiSEE
The original download URL supplied by the study user was:
https://www.kaggle.com/datasets/olgaparfenova/daisee/download?datasetVersionNumber=1
Mirror/source byte equivalence has not been established. Mirror access does not replace provider terms.

No videos, images, labels, clip manifest, predictions, embeddings or model weights are shipped.
The subset manifest is generated locally from the user's authorized label files.
The expected manifest SHA-256 is a provenance check, not a distribution permission.
Do not commit generated data. ResNet-18 weights are fetched by torchvision from the upstream provider on first extraction; their separate terms apply.

Cite the dataset works: Gupta et al., DAiSEE: Towards User Engagement Recognition in the Wild, arXiv:1609.01885; and Kamath et al., A Crowdsourced Approach to Student Engagement Recognition in e-Learning Environments, WACV 2016.
